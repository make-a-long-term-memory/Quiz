## 점수 받기 설정 (구글 시트, 한 번만)

학생이 퀴즈를 끝까지 풀면 3초 뒤 자동으로 선생님의 구글 시트에 한 줄씩 시간 순으로 쌓여요. 같은 학번(학년, 반, 번호)은 퀴즈마다 3번까지만 받아요. 점수는 시트의 `퀴즈 점수` 탭에 쌓여요.

1. 구글 드라이브에서 **새 구글 시트**를 만들어요(이름 예: `퀴즈 점수`).
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 원래 있던 코드를 모두 지우고 이 저장소의 `score_apps_script.gs` 내용을 붙여넣은 뒤 저장해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**을 골라요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 허용하면 `https://script.google.com/macros/s/…/exec` 주소가 나와요. 복사해요.
6. 이 저장소의 `score-config.js`를 열어(연필 아이콘) `window.SCORE_URL = "";`의 따옴표 안에 주소를 붙여넣고 저장(Commit)해요.

- 액세스 권한은 꼭 **모든 사용자**여야 해요. 학교 구글 계정에서 이 항목이 막혀 있으면 개인 구글 계정으로 시트를 만들어 주세요.
- 시트는 **파일 → 다운로드 → Microsoft Excel(.xlsx)**로 내려받을 수 있어요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요(주소는 그대로예요).
